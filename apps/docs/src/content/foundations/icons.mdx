# Icons

Browse the icons in `@hobiui/icons`, search by name, and copy a ready-to-use import and JSX snippet from any icon.

<h2 id="usage">Use an icon</h2>

Icons use `currentColor`, default to 24 by 24 pixels, and accept a numeric or CSS length `size`. Use `title` or `aria-label` when the icon itself conveys information; decorative icons should be hidden from assistive technology.

<h2 id="accessible-icons">Accessibility</h2>

- Hide a decorative icon from assistive technology with `aria-hidden="true"`.
- Give an icon-only button an accessible name on the button, such as `aria-label="Search"`.
- Keep pointer and keyboard interaction on the control that contains the icon.
- Pair icon color with another cue when it communicates state or status.
