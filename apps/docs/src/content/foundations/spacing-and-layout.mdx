<h2 id="apply-spacing">Apply spacing tokens</h2>

Use spacing tokens in CSS properties such as `gap`, `padding`, and `margin`. Keep each token tied to a relationship in the layout, rather than choosing a value independently for every element.

<h2 id="responsive-layout">Responsive layout</h2>

Use flexible grid tracks and min/max constraints so content can shrink before it overflows. Add breakpoints when the layout itself needs to change, such as moving a two-column composition into one column. Choose breakpoint values based on the content and available space in your application.

<CodeBlock code={`.content-grid {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: var(--chakra-space-6);
}

@media (max-width: 47.5em) {
  .content-grid {
    grid-template-columns: minmax(0, 1fr);
  }
}`} />
