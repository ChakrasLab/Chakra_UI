# Typography

Use the shared font families and size tokens to keep text consistent across components. Establish hierarchy with semantic HTML, weight, and spacing before introducing one-off sizes.

<h2 id="font-families">Font families</h2>

The token package provides a sans-serif stack for interface text and a serif stack used for selected brand moments. Use the sans-serif token for product content unless a component has a clear reason to use the alternate family.

These tokens describe the current compact interface scale. At the browser's default 16px root size they resolve to 11px, 12px, 14px, and 16px; rem values also respect the user's root text-size setting. Page headings use responsive styles rather than this body-text scale.

<h2 id="hierarchy">Build hierarchy</h2>

- Use headings in order (`h1`, then `h2`, then `h3`) to express document structure.
- Keep paragraphs at a comfortable reading width and use line height that supports scanning.
- Reserve muted text styles for supporting information that remains readable.
- Avoid assigning meaning through font size alone; include a clear label or structure.
