All native button attributes are forwarded, including `disabled`, `name`, `value`, and `type`.

<h2 id="selected-state">Selected and toggle states</h2>

`active` changes the visual treatment; it does not add toggle semantics by itself. For a toggle, expose the state with `aria-pressed` and update it when the user activates the button.

<h2 id="forms">Buttons in forms</h2>

The component defaults to `type="button"` to avoid accidental form submission. Set `type="submit"` for the form's submit action. Use `disabled` when the action cannot currently be completed, and explain the reason in nearby text when it is not obvious.

<h2 id="accessibility">Accessibility</h2>

- Use a concise label that describes the action.
- Give icon-only buttons an accessible name with visible text or `aria-label`.
- Keep a visible keyboard focus indicator and do not use a button for navigation; use a link for navigation.

`@hobiui/react` is prepared for npm publishing but has not been released yet.
